본 홈페이지는 회원가입·로그인·온라인 결제 서비스를 운영하지 않습니다. 상담 신청에 필요한 최소 정보만 수집하며, 주민등록번호·비밀번호·계좌번호 등 민감하거나 불필요한 정보는 입력하지 마십시오.

3. 개인정보의 처리 및 보유 기간

회사 관리 정보상담 처리 완료 후 지체 없이 삭제. 다만 관계 법령에 따라 보존할 필요가 있는 경우에는 해당 기간 동안 보관합니다.
Formspree 제출 이력회사가 사용하는 Formspree 플랜과 계정 설정에 따른 보관기간이 적용됩니다. 회사는 실제 플랜의 보관·삭제 기능을 확인하고 상담 처리 목적 달성 후 삭제하도록 관리합니다.
이메일·다운로드 자료상담 처리 목적 달성 후 지체 없이 삭제하도록 관리합니다.

Formspree 공식 문서상 제출 이력 보관기간은 플랜에 따라 달라질 수 있으므로, 회사는 홈페이지에 Formspree의 보관기간을 임의의 3개월 또는 1년으로 단정하지 않습니다. 회사가 별도 보관기간을 확정하는 경우 실제 Formspree 설정과 이메일·다운로드 자료의 삭제 기준을 함께 조정합니다.

4. 개인정보의 파기 절차 및 방법

회사는 처리 목적이 달성되거나 보유기간이 끝난 개인정보를 지체 없이 파기합니다. 전자적 파일은 복구·재생이 어려운 방법으로 삭제하고, 출력물은 분쇄 또는 소각 등의 방법으로 파기합니다. 법령상 보존이 필요한 정보는 다른 개인정보와 분리하여 해당 기간 동안 보관한 후 파기합니다.

회사는 이용자의 개인정보를 상담 처리 목적의 범위에서만 이용하며, 법률상 근거가 있거나 이용자의 별도 동의가 있는 경우를 제외하고 제3자에게 제공하지 않습니다. 현재 상담 신청 정보의 일반적인 제3자 제공은 없습니다.

7. 개인정보의 안전성 확보조치

회사는 홈페이지와 상담 처리 과정에서 개인정보의 안전성을 확보하기 위해 다음 조치를 적용하거나 운영을 위해 노력합니다.

  1. HTTPS 기반 홈페이지와 상담 전송 경로를 사용합니다.
  2. GitHub 저장소에는 API 비밀키·비밀번호·주민등록번호 등 민감정보를 저장하지 않습니다.
  3. GitHub 계정의 2단계 인증, 저장소 권한 최소화, 배포 변경 검토 등 계정·배포 보안을 유지합니다.
  4. Formspree, 이메일함 및 다운로드된 상담자료의 접근권한을 필요한 담당자로 제한하고 목적 달성 후 삭제합니다.
  5. Formspree가 제공하는 암호화·접근통제 등 수탁 서비스의 보안조치와 정책을 확인합니다.

본 사이트의 HTTPS와 GitHub Pages 보안은 홈페이지 전송·배포 보호를 위한 조치이며, 외부 링크로 이동한 사이트의 보안 수준을 회사가 보증하는 것은 아닙니다.
