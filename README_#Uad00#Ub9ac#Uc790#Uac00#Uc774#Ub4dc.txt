=====================================================================
 자림인포시스템(주) 홈페이지 — 관리자 작업 매뉴얼
=====================================================================
이 문서는 코딩을 몰라도 홈페이지 내용을 직접 고칠 수 있도록,
실제로 자주 하게 되는 "작업" 단위로 정리한 매뉴얼입니다.
목차에서 하고 싶은 작업을 찾아 그 부분만 보셔도 됩니다.

목차
 0. 시작하기 전에 꼭 읽어주세요 (공통 원칙 · 반영 방법)
 1. 일반 문구(텍스트) 수정하기
 2. 유튜브 영상 교체하기
 3. 회사소개 영상 추가하기
 4. 자료실에 새 카테고리(메뉴항목) 만들기
 5. 자료실에 자료 추가 · 삭제하기 (PDF 업로드 포함)
 6. 제품 정보 추가 · 수정하기
 7. 연락처 · 주소 · 영업시간 변경하기
 8. 거래(구축) 실적 기관명 추가하기
 9. 자주 묻는 질문(FAQ) 추가하기
10. 실수했을 때 되돌리기

=====================================================================
 0. 시작하기 전에 꼭 읽어주세요
=====================================================================
[핵심 파일 하나]
이 홈페이지는 js/site-data.js 파일 하나에 모든 문구와 데이터가
들어있고, 화면 디자인(js/main.js, css/style.css)은 그 데이터를
읽어서 자동으로 그려주는 구조입니다.

  → 문구를 고치거나 자료를 추가/삭제하는 작업은
    거의 대부분 js/site-data.js 파일 안에서만 이루어집니다.
    html, css, main.js 파일은 특별한 언급이 없는 한 건드릴 필요가
    없습니다.

[수정 원칙 3가지]
  1) 따옴표(' ') 안에 있는 한글/숫자/영어만 원하는 내용으로 바꾸세요.
  2) 따옴표, 쉼표(,), 중괄호({ }), 대괄호([ ])는 절대 지우지 마세요.
     이 4가지 기호의 짝이 하나라도 안 맞으면 사이트 전체가 하얀
     화면으로 보이는 오류가 날 수 있습니다.
  3) 목록에 항목을 추가하고 싶을 때는, 가장 비슷한 항목 하나를
     통째로 복사해서 바로 아래(또는 위)에 붙여넣고 내용만
     바꾸는 방식이 가장 안전합니다. 이 문서의 모든 작업 설명이
     이 방식을 기준으로 되어 있습니다.

[수정 사항을 실제 홈페이지에 반영하는 방법 — 공통]
현재 홈페이지는 GitHub 저장소(datawave9/jariminfo-site5)의 내용이
그대로 화면에 보이는 방식(GitHub Pages)으로 운영되고 있습니다.

 방법 A. 파일 하나의 내용만 고칠 때 (문구 수정 등 대부분의 경우)
  1) https://github.com/datawave9/jariminfo-site5 접속
  2) 수정할 파일(예: js/site-data.js) 클릭
  3) 화면 오른쪽 위 연필 아이콘(Edit this file) 클릭
  4) 내용 수정
  5) 화면 아래로 내려가 "Commit changes..." 클릭
     → 초록색 "Commit changes" 버튼을 한 번 더 클릭
  6) 1~2분 안에 실제 홈페이지에 자동 반영됩니다.
     (별도의 "배포" 버튼은 없습니다.)

 방법 B. 파일(PDF, 이미지 등)을 새로 올리거나 통째로 바꿔치기할 때
  1) 해당 폴더(예: assets/docs)로 이동
  2) 오른쪽 위 "Add file" → "Upload files" 클릭
  3) 파일을 끌어다 놓거나 선택 → 아래 "Commit changes" 클릭
     (같은 파일명으로 올리면 기존 파일을 자동으로 덮어씁니다)

이 문서의 모든 작업은 마지막에 이 "방법 A" 또는 "방법 B"로
GitHub에 반영하는 것으로 마무리됩니다. (매번 반복해서 적지 않고
아래에서는 "GitHub에 반영하세요"로 줄여서 표기합니다.)

[수정 전 안전장치]
js/site-data.js처럼 중요한 파일을 고치기 전에는, 수정 전 내용을
메모장 등에 미리 복사해 두시면 문제가 생겨도 바로 되돌릴 수 있어
안전합니다. (10번 항목에 GitHub 자체 되돌리기 기능도 안내되어
있습니다.)

 1. 일반 문구(텍스트) 수정하기
=====================================================================
예시: 홈 화면 맨 위 문구를 바꾸고 싶은 경우

1) js/site-data.js를 엽니다.
2) 화면에서 "3. 홈 화면 — 히어로(맨 위) 영역" 주석을 찾습니다.
   (Ctrl + F로 "히어로" 또는 "hero:"를 검색하면 빠르게 찾을 수 있습니다.)
3) 아래처럼 되어 있는 부분에서 따옴표 안의 문구만 바꿉니다.

   hero: {
     title1: '끊기지 않는 연결이,',        ← 이 부분만 수정
     title2: '비즈니스의 기본기입니다.',    ← 이 부분만 수정
     desc: '...',                          ← 이 부분만 수정
   },

4) 저장 후 GitHub에 반영하세요.

같은 방식으로 아래 항목들도 원하는 문구로 바꿀 수 있습니다.
(모두 js/site-data.js 안에 있으며, 괄호 안 검색어로 빠르게 찾으세요.)

  - 회사 기본 정보(전화번호, 이메일 등)          → 검색어: company:
  - 상단 메뉴 이름(홈/회사소개/제품소개 등)       → 검색어: nav:
  - 취급 브랜드 안내 문구                         → 검색어: brandNotice:
  - 홈 화면 숫자 카드(창립연도, 실적 수 등)       → 검색어: stats:
  - "왜 iPECS인가" 문구                          → 검색어: whyIpecs:
  - 회사소개 페이지 소개 문구                     → 검색어: aboutIntro:
  - 회사 연혁                                     → 검색어: history:
  - 도입 프로세스(상담~유지보수 5단계)            → 검색어: process:
  - 자림인포시스템(주)을 선택해야 하는 이유       → 검색어: differentiators:

목록(리스트) 형태로 된 항목(문장 앞에 { }가 여러 번 반복되는 것)은
그중 한 줄({ }로 묶인 덩어리 하나)을 복사 → 붙여넣기 → 내용 수정
하는 방식으로 개수를 늘리거나 줄일 수 있습니다.

 2. 유튜브 영상 교체하기
=====================================================================
홈 화면의 "브랜드 필름" 영상은 유튜브 영상 ID 하나로 연결되어
있어서, ID만 바꾸면 자동으로 다른 영상으로 교체됩니다.

1) 바꾸고 싶은 유튜브 영상의 주소를 확인합니다.
   예) https://www.youtube.com/watch?v=ABCDEFGHIJK
   → "v=" 뒤에 있는 ABCDEFGHIJK 부분이 영상 ID입니다.

2) js/site-data.js에서 "3-1. 홈 화면 — 브랜드 필름" 주석을 찾습니다.
   (검색어: youtubeId)

3) 아래처럼 되어 있는 부분을 수정합니다.

   video: {
     kicker: 'Brand Film',
     title: '영상으로 만나는 iPECS',              ← 필요하면 제목도 수정
     desc: '...',                                  ← 필요하면 설명도 수정
     youtubeId: 'WT20hhceELU',                     ← 이 부분을 새 영상 ID로 교체
     caption: 'iPECS, Anywhere Anytime — ...'       ← 필요하면 캡션도 수정
   },

   예) 새 영상 ID가 ABCDEFGHIJK라면
   youtubeId: 'ABCDEFGHIJK',

4) 저장 후 GitHub에 반영하세요. 홈 화면 썸네일과 재생 버튼이
   자동으로 새 영상 기준으로 바뀝니다.

=====================================================================
 3. 회사소개 영상 추가하기
=====================================================================
현재 홈 화면에는 영상을 한 개만 넣을 수 있는 자리(브랜드 필름)가
있습니다. 회사소개 영상을 새로 추가하고 싶다면 아래 두 가지 방법 중
상황에 맞는 것을 선택하세요.

[방법 A] 기존 브랜드 필름 자리를 회사소개 영상으로 바꾸기
  홈 화면에 영상이 하나만 보여도 괜찮다면 가장 간단한 방법입니다.
  → 위 "2. 유튜브 영상 교체하기"와 똑같은 방법으로, youtubeId 값을
    회사소개 영상의 유튜브 ID로 바꾸면 됩니다. title/desc/caption
    문구도 "iPECS 브랜드 필름" 대신 "자림인포시스템(주) 회사소개"
    등으로 함께 바꿔주시면 자연스럽습니다.

[방법 B] 자료실에 "회사소개 영상"으로 추가하기 (기존 브랜드 필름은 유지)
  홈 화면의 iPECS 브랜드 필름은 그대로 두고, 자료실에 별도
  영상 링크를 추가하고 싶다면 아래처럼 합니다.
  (자료실에 새 카테고리를 만드는 자세한 방법은 4번 항목 참고)

  1) 회사소개 영상을 유튜브에 먼저 올려두고 그 주소를 준비합니다.
     예) https://www.youtube.com/watch?v=ABCDEFGHIJK
  2) js/site-data.js에서 "6-3. 자료실" 안의 items 배열을 찾습니다.
     (검색어: items: [)
  3) 아래처럼 새 항목을 하나 추가합니다. (기존 항목 중 아무거나
     하나를 복사해서 값만 바꾸는 것이 가장 안전합니다.)

     {
       icon: 'external-link',
       category: '홍보영상',
       title: '자림인포시스템(주) 회사소개 영상',
       desc: '2분 만에 보는 회사소개 · 유튜브 영상',
       href: 'https://www.youtube.com/watch?v=ABCDEFGHIJK',
       type: 'external',
       badge: '영상',
     },

  4) 저장 후 GitHub에 반영하세요. category에 새로운 이름
     ("홍보영상")을 적었기 때문에, 자료실 화면에 "홍보영상"이라는
     그룹 제목이 자동으로 새로 생기고 그 아래 이 영상 링크가
     표시됩니다.

=====================================================================
 4. 자료실에 새 카테고리(메뉴항목) 만들기
=====================================================================
자료실 페이지는 js/site-data.js의 resources.items 배열에 있는
자료를 하나씩 카드로 보여주며, 이때 category 값이 같은 자료끼리
자동으로 묶여서 그 위에 카테고리 제목이 저절로 생성됩니다.

  → 즉, 카테고리(메뉴항목)를 등록하는 별도 화면이나 설정은 없고,
    자료 하나를 추가하면서 category 값에 원하는 이름을 적기만
    하면 그 이름의 그룹이 화면에 자동으로 생깁니다.

현재 만들어져 있는 카테고리 예시: 회사소개 / 단말기 / 제조사 자료실

예시: "통신공사 자료"라는 새 카테고리를 만들고 싶은 경우
1) js/site-data.js에서 resources.items 배열을 찾습니다.
   (검색어: items: [)
2) 기존 자료 항목 하나를 통째로 복사해서 붙여넣습니다.
3) category 값에 기존에 없던 새 이름("통신공사 자료")을 적고,
   나머지 값(title, desc, href 등)도 새 자료에 맞게 바꿉니다.

   {
     icon: 'file-text',
     category: '통신공사 자료',
     title: '정보통신공사 시공 사례 안내',
     desc: '구내통신 · CCTV · 방송설비 시공 사례 모음',
     href: 'assets/docs/통신공사_시공사례.pdf',
     type: 'download',
     badge: 'PDF',
   },

4) 저장 후 GitHub에 반영하세요. "통신공사 자료"라는 카테고리
   제목이 자료실 화면에 자동으로 새로 생깁니다.

카테고리 안의 자료를 전부 지우면 그 카테고리 제목도 화면에서
자동으로 함께 사라집니다. (자료 추가/삭제의 자세한 방법과 각
필드의 의미는 바로 다음 5번 항목을 참고하세요.)

=====================================================================
 5. 자료실에 자료 추가 · 삭제하기 (PDF 업로드 포함)
=====================================================================
[자료 1건의 구조]
자료실의 자료 1건은 아래처럼 7개의 값으로 이루어져 있습니다.

   {
     icon: 'file-text',       ← 아이콘 종류. 3가지 중 하나만 사용 가능
                                 'file-text'(문서), 'book-open'(설명서),
                                 'external-link'(외부 링크)
     category: '단말기',       ← 그룹(카테고리) 이름. 4번 항목 참고
     title: '자료 제목',       ← 카드에 굵게 표시되는 제목
     desc: '한 줄 설명',       ← 제목 아래 작은 설명 문구
     href: '연결 주소',        ← 아래 [href 정하는 법] 참고
     type: 'download',        ← 'download'(자체 파일, 클릭 시 다운로드)
                                 또는 'external'(외부 링크, 새 탭으로 열림)
     badge: 'PDF',             ← 카드 오른쪽에 표시되는 짧은 문구
                                 (예: 'PDF', 'PDF · 공식', '공식 사이트')
   },

[href 정하는 법]
 - 우리 회사가 직접 만든 파일(자체 제작 PDF 등)을 새로 올리는 경우
    ① 파일을 assets/docs 폴더 "안에" 먼저 업로드합니다.
       (위 "0번 — 방법 B" 참고)
    ② href 값은 'assets/docs/파일명.pdf' 형태로 적습니다.
    ③ type은 'download'로 둡니다.
 - 제조사 홈페이지 등 외부 자료로 연결하는 경우
    ① href 값에 해당 페이지의 전체 인터넷 주소(https://로 시작)를
       적습니다.
    ② type은 'external'로 둡니다.

[예시 1] 기존 "단말기" 카테고리에 새 사용설명서 추가하기
   1) js/site-data.js → resources.items 배열에서 category가
      '단말기'인 항목 하나를 복사합니다.
   2) 아래처럼 값을 바꿔서 붙여넣습니다.

      {
        icon: 'book-open',
        category: '단말기',
        title: 'iPECS 1080i 화상전화기 빠른 사용 안내',
        desc: '기본 조작법 요약 카드',
        href: 'assets/docs/1080i_quick_guide.pdf',
        type: 'download',
        badge: 'PDF',
      },

   3) PDF 실물 파일을 assets/docs 폴더에 업로드합니다. (방법 B)
   4) site-data.js 저장 후 GitHub에 반영하세요.

[예시 2] 회사소개서 PDF를 새 버전으로 교체하기 (파일명을 그대로
유지하는 경우 — 가장 간단합니다)
   1) assets/docs 폴더로 이동
   2) "Add file" → "Upload files"로 새 PDF를 같은 파일명
      (자림인포시스템_회사소개서.pdf)으로 업로드
      → 자동으로 기존 파일을 덮어씁니다.
   3) site-data.js는 고칠 필요가 없습니다. (href 값이 그대로
      이 파일명을 가리키고 있기 때문입니다.)

[자료 삭제하기]
   해당 자료의 { 부터 } , 까지(중괄호와 뒤 쉼표까지) 전체를
   선택해서 지우면 됩니다. 어떤 카테고리의 자료를 전부 지우면
   그 카테고리 제목도 화면에서 자동으로 사라집니다.

=====================================================================
 6. 제품 정보 추가 · 수정하기
=====================================================================
[제품소개 페이지(products.html)의 상세 제품]
js/site-data.js의 products 배열에 있으며(검색어: products: [),
제품 1개는 아래 구조로 되어 있습니다.

   {
     id: 'ucm',
     category: '대용량 IP-PBX',
     name: 'iPECS UCM',
     img: '이미지 주소',
     tagline: '한 줄 요약 문구',
     desc: '제품 설명 문단',
     specs: [
       { k: '수용 규모', v: '노드당 최대 60,000 / ...' },
       { k: '이중화', v: '...' },
       ... 스펙 항목을 필요한 만큼 추가/삭제 가능
     ]
   },

새 제품을 추가하려면 기존 제품 { ... } 블록 하나를 통째로 복사해서
products 배열 안에 붙여넣고, id/category/name/img/tagline/desc를
새 제품에 맞게 바꾼 뒤 specs 목록도 원하는 스펙으로 교체합니다.
(specs 안의 { k: '항목명', v: '값' } 한 줄이 화면의 표 한 줄입니다.)

[제품 이미지(img) 관련 안내]
현재 제품 이미지는 iPECS 공식 홈페이지(ipecs.co.kr)에 있는 이미지
주소를 그대로 연결해서 쓰고 있습니다. 제조사 서버 사정으로 이미지
주소가 예고 없이 바뀌거나 접속이 막힐 수 있으므로, 장기적으로는
이미지를 다운로드해 assets/img 폴더에 올린 뒤 img 값을
'assets/img/파일명.jpg' 형태로 바꿔 자체 호스팅하는 것을
권장합니다. (업로드 방법은 0번 — 방법 B와 동일합니다.)

[홈 화면 제품 요약 카드(6개)]
검색어: productSummary: — 제품소개 페이지의 상세 제품과 별개로,
홈 화면 중간에 보이는 요약 카드입니다. 구조는 아래와 같이 더
간단합니다.

   { id: 'ucm', tag: 'PBX', name: 'iPECS UCM', desc: '...', img: '...' },

[제품 규모별 비교표]
검색어: comparisonTable: — "몇 인 규모에는 어떤 제품"을 안내하는
표입니다. rows 배열 안의 한 줄이 표의 한 행입니다.

   { size: '5 ~ 50인', sites: '단일 사업장', pick: 'iPECS eMG100', reason: '...' },

모두 수정 후에는 GitHub에 반영하세요.

10. 실수했을 때 되돌리기
=====================================================================
js/site-data.js를 고치다가 사이트가 하얀 화면으로 보이거나
이상하게 깨졌다면, 아래 방법으로 안전하게 이전 상태로 되돌릴 수
있습니다.

1) https://github.com/datawave9/jariminfo-site5 접속
2) 화면 오른쪽 위 "History"(또는 시계 모양 아이콘) 클릭
   → 지금까지의 모든 수정 기록이 시간순으로 나열됩니다.
3) 문제가 생기기 전의 기록을 찾아 클릭 → 그 시점의 파일 내용을
   확인할 수 있습니다.
4) 그 시점의 파일 내용을 복사해서, 현재 파일을 편집 화면에서
   전부 지우고 붙여넣은 뒤 "Commit changes"를 누르면 그 상태로
   되돌아갑니다.

가장 안전한 습관은 site-data.js처럼 중요한 파일을 고치기 전에
수정 전 내용을 미리 메모장에 복사해 두는 것입니다. 그러면 위 과정
없이 바로 붙여넣기만 해도 되돌릴 수 있습니다.
